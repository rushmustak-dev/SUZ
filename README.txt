==============================================
СИСТЕМА УПРАВЛЕНИЯ ЗАКАЗАМИ ДЛЯ ПРОИЗВОДСТВА
==============================================

Описание:
---------
Система управления заказами для производственного предприятия.
Включает создание заказов, отслеживание статусов, управление файлами,
уведомления по email и календарь заказов.

Функциональность:
----------------
1. Создание заказов с присвоением уникального номера
2. Управление статусами заказов
3. Назначение конструкторов и установка сроков
4. Загрузка файлов (исходники и разработка)
5. Уведомления по email
6. Календарь заказов
7. Административная панель
8. Разделение прав доступа по ролям

Требования:
-----------
- Python 3.8+
- pip (менеджер пакетов)

Установка и запуск:
-------------------

1. Клонирование или распаковка проекта

2. Создание виртуального окружения (рекомендуется):
   python -m venv venv
   
   Активация виртуального окружения:
   - Windows: venv\Scripts\activate
   - Linux/Mac: source venv/bin/activate

3. Установка зависимостей:
   pip install -r requirements.txt

4. Инициализация базы данных:
   - Создайте файл миграции:
     flask db init
   - Создайте миграцию:
     flask db migrate -m "Initial migration"
   - Примените миграцию:
     flask db upgrade

5. Создание администратора:
   python create_admin.py
   По умолчанию создается пользователь:
   Email: admin@example.com
   Пароль: admin123

6. Настройка почты (опционально):
   - Отредактируйте файл instance/settings.json
   - Или настройте через административную панель после входа

7. Запуск приложения:
   python run.py
   Приложение будет доступно по адресу: http://localhost:5000

8. Открытие в браузере:
   http://localhost:5000

Роли пользователей:
------------------
1. admin - Администратор (полный доступ)
2. manager - Руководитель (создание заказов, назначение конструкторов)
3. designer - Конструктор (работа с заказами, загрузка чертежей)
4. supply - Снабжение (закупка материалов)
5. production - Производство (изготовление и монтаж)
6. client - Клиент (просмотр своих заказов)

Настройка почты для Gmail:
-------------------------
1. Войдите в аккаунт Google
2. Включите двухфакторную аутентификацию
3. Создайте пароль приложения:
   https://myaccount.google.com/apppasswords
4. Используйте пароль приложения в настройках почты

Устранение неполадок:
--------------------

1. Ошибка "ImportError: No module named..."
   - Активируйте виртуальное окружение
   - Переустановите зависимости: pip install -r requirements.txt

2. Ошибка подключения к базе данных
   - Убедитесь, что папка instance существует
   - Проверьте права на запись в папке проекта

3. Письма не отправляются
   - Проверьте настройки почты
   - Для Gmail используйте пароль приложения
   - Проверьте настройки безопасности почтового сервера

4. Файлы не загружаются
   - Проверьте права на запись в папку uploads
   - Убедитесь, что размер файла не превышает 16MB

Безопасность:
------------
1. Измените SECRET_KEY в app/config.py для продакшн
2. Используйте переменные окружения для чувствительных данных
3. Настройте HTTPS для продакшн окружения
4. Регулярно создавайте резервные копии базы данных
